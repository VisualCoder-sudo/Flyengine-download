# Flyengine public downloads

Installers for [Flyengine](https://github.com/VisualCoder-sudo/Flyengine-download/releases/latest), a 3D game engine and editor.
This repository holds **only the finished installers**. There is no source code here.

Get them from the Download page on the Flyengine website, or from the [latest release](https://github.com/VisualCoder-sudo/Flyengine-download/releases/latest).

| Platform | File |
|---|---|
| Windows | `Flyengine-Setup.exe` |
| Linux, any distro | `Flyengine-x86_64.AppImage` |
| Linux, Fedora / openSUSE / RHEL | `Flyengine-x86_64.rpm` |

macOS is not available yet.

The installers are not code-signed yet, so Windows SmartScreen may warn when you run `Flyengine-Setup.exe`.
Choose **More info**, then **Run anyway**. SHA-256 checksums are in each release's notes.
